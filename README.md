# IMovies (MERN)
Backend: `cd backend && cp .env.example .env && npm i && npm run seed && npm start`
Frontend: `cd frontend && npm i && npm run dev` (proxies /api and sockets to :5000)
Seed logins: admin@imovies.com / admin123 (admin). Register for normal users.
Mock payment: enter 4 digits; `0000` simulates a declined payment.
